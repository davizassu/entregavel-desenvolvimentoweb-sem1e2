# Acervo Davizassu!

## Sobre o projeto

Um projeto prático de desenvolvimento web construído para aplicar e treinar conceitos fundamentais de HTML semântico e estilização avançada com CSS. O site funciona como um portfólio de estudos, documentando a jornada de aprendizado em tecnologia, e oferece um espaço interativo de contato focado em interação com novos usuários. 

## Funcionalidades e Tecnologias

Aplicação prática de fundamentos de desenvolvimento frontend, incluindo:
* Estilização de layout aplicando conceitos de box model (margens, paddings, cores de fundo).
* Flexbox para alinhamento e distribuição de espaço (flex-direction: column, justify-content: space-between, gap).
* Efeitos visuais e interativos como bordas arredondadas (border-radius), sombras suaves (box-shadow), e mudanças de estado durante a interação do usuário (:focus e :hover).

## Estrutura de Arquivos

* **index.html:** Página principal com as seções de conteúdo estático.
* **contato.html:** Página contendo o formulário interativo de inscrição.
* **css/style.css:** Arquivo único de folhas de estilo, compartilhado entre ambas as páginas para manter a consistência visual.

## Como visualizar o projeto

1. Salve todos os arquivos em uma única pasta principal no seu computador.
2. Certifique-se de que o arquivo style.css esteja dentro de uma subpasta chamada css.
3. Clique duas vezes no arquivo index.html para abri-lo diretamente no seu navegador padrão (Chrome, Firefox, Edge, etc.). Nenhuma instalação de servidor é necessária.
