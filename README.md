Acervo Davizassu!
Um projeto prático de desenvolvimento web construído para aplicar e treinar conceitos fundamentais de HTML semântico e estilização avançada com CSS. O site funciona como um portfólio de estudos, documentando a jornada de aprendizado em tecnologia, e oferece um espaço interativo de contato focado na comunidade "Coffee & Code".
🚀 Funcionalidades
 * Navegação em Página Única: Menu com links de âncora (#) que direcionam o usuário para as seções "Apresentação", "Sobre" e "Serviços" dentro da mesma página.
 * Formulário de Inscrição (NewsLtt): Página de contato estruturada com campos para nome, e-mail, seleção de interesses (projetos no GitHub, prática de inglês) e área de mensagem livre.
 * Layout Inteligente com Flexbox: Estrutura de campos organizada e alinhada utilizando display: flex, incluindo uma disposição lado a lado para os campos de Nome e E-mail.
 * Acessibilidade Básica: Uso correto de tags <label> associadas aos seus respectivos <input> e <select> através dos atributos for e id, permitindo navegação via teclado.
🛠️ Tecnologias Utilizadas
 * HTML5: Estruturação semântica com caixas lógicas como <header>, <main>, <section>, <footer> e a criação de formulários agrupados (<form>).
 * CSS3:
   * Estilização de layout aplicando conceitos de box model (margens, paddings, cores de fundo).
   * Flexbox para alinhamento e distribuição de espaço (flex-direction: column, justify-content: space-between, gap).
   * Efeitos visuais e interativos como bordas arredondadas (border-radius), sombras suaves (box-shadow), e mudanças de estado durante a interação do usuário (:focus e :hover).
📂 Estrutura de Arquivos
 * index.html: Página principal com as seções de conteúdo estático.
 * contato.html: Página contendo o formulário interativo de inscrição.
 * css/style.css: Arquivo único de folhas de estilo, compartilhado entre ambas as páginas para manter a consistência visual.
💻 Como visualizar o projeto
 * Salve todos os arquivos em uma única pasta principal no seu computador.
 * Certifique-se de que o arquivo style.css esteja dentro de uma subpasta chamada css.
 * Clique duas vezes no arquivo index.html para abri-lo diretamente no seu navegador padrão (Chrome, Firefox, Edge, etc.). Nenhuma instalação de servidor é necessária.
